
# HubPedidos

Projeto acadêmico desenvolvido em C# com .NET 10 para processamento e classificação de pedidos.

## Objetivo

Desenvolver uma aplicação organizada em camadas para processar pedidos, validar informações e classificar solicitações.

## Tecnologias utilizadas

- C#
- .NET 10
- ASP.NET Core
- xUnit para testes automatizados
- Git e GitHub

## Estrutura do projeto

- **Domain:** entidades, contratos e regras de domínio.
- **application:** mapeamentos e lógica da aplicação.
- **Api:** camada de API.
- **Tests:** testes automatizados.
